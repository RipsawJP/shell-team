- decision: `--paths` consumes every remaining argument in the parse loop and rejects any argument beginning with `-` there, so `--paths ok --all` is a usage error from the path check, while `--all --paths ok` and `--base X --paths ok` are caught by a post-loop conflict check that runs before the existing `--all`/`--base` check.
  reason: Keeping the existing parse branches and their messages untouched preserves byte identity for the other modes; the two orders of the conflict need different detection points because everything after `--paths` is a path by grammar.
  grounding: `.shell-team/specs/T-1182-local-mode-shape-scan.md` D1 and AC2, AC4.

- decision: Each named path is resolved by physicalizing its parent directory (`cd`/`pwd -P`) and appending the leaf unresolved, then expressed relative to the physical repository root; a leaf that is `.` or `..` is resolved whole.
  reason: The leaf must stay unfollowed so a named symlink is scanned by its target string, while the root comparison needs physical paths (a temp root may sit behind a symlink); a path outside the root is a structural error rather than a silent pass.
  grounding: `.shell-team/specs/T-1182-local-mode-shape-scan.md` D1 and AC3.

- decision: A directory is walked with `find` (pruning any `.git` entry, listing regular files and symlinks, never following), and only a regular text file that was actually read counts toward the "read something" requirement; known-shapes-skipped files, binary files and symlinks do not.
  reason: The fail-closed direction (exit 2 when nothing was read) must also cover a directory holding only binary files or only symlinks, which is an instance of the never-dropped N2 property.
  grounding: `.shell-team/specs/T-1182-local-mode-shape-scan.md` D1 and AC2.

- decision: In the block line, a `local`-mode round in which the role wrote no record file does not run `--paths` with no argument; the role reports the `- shape-scan:` line with a zero count and `rc=n/a`.
  reason: `--paths` with no path exits 2 by design, and a role should not read that as a failed scan when there is nothing to scan; the existing summary line already allows a zero count.
  grounding: `.shell-team/specs/T-1182-local-mode-shape-scan.md` `## Notes for engineer` (Block line).
