- decision: (rework round 5, Codex review round 1 Major 1 — `refusal-class-incomplete`) detected a NUL byte (0x00) in a role file's source by byte-count comparison (`wc -c` on the source vs. `wc -c` after `LC_ALL=C tr -d '\000' < "$SRC"`), as a check separate from and preceding the existing bracket-expression `grep` over `\x01`–`\x1f`/`\x7f`, rather than prepending `\x00` to that same bracket expression, switching to `grep -P '\x00'`, or scanning with `od`/`awk`.
  reason: prepending `\x00` to the existing `grep -q $'[...]'` pattern is the fix that looks obvious and does nothing: bash's own ANSI-C quoting (`$'...'`) truncates a string at its first NUL byte when building an argv entry, so the pattern argument grep would receive is silently truncated before grep ever runs — this is the actual root cause the review's reproduction exposed, not a wrong byte range. `grep -P` was excluded by this round's own briefing (not portable). `od`/hex-scanning was rejected because concatenating hex-digit pairs from an `od` dump and grepping for the literal substring `00` risks a false match straddling two adjacent bytes (e.g. `a0` next to `0a`) that never formed an actual NUL. A byte-count comparison via `tr -d '\000'` never needs to pass a NUL through argv at all — `'\000'` in the `tr` command string is four ordinary ASCII characters that `tr` itself interprets as an octal escape, not an embedded NUL — and is portable (GNU and BSD `tr` both support octal escapes in a delete set).
  grounding: `bin/gen-codex-agents.sh`'s new comment block directly above the byte-count check ("bash's own $'\\x00' ANSI-C quoting truncates ... a single `grep -q $'[...\\x00...]'` invocation can never actually search for a NUL"); `.shell-team/reviews/T-1134.md` Major 1 ("The character class in the script is `[\\x01\\x02...\\x1f\\x7f]` — it starts at `\\x01` and never includes `\\x00`... Suggested fix: extend the byte-range check to include `\\x00`") — the suggested one-line fix is exactly the form this decision declines, for the argv-truncation reason recorded here; own mutation self-check (disabled the new check, reproduced the review's exact repro shape — `rc=0`, 4 files written — restored byte-identically, reproduced the refusal).
