Prose context for the triples below (outside the marker region, not part of
the checker's schema): this task profiled `bin/check-handoff.sh` before
changing it, found the `## Active`-only bash loop dominant over the
whole-file `awk` extraction on the profiling board built to stress both

isolated micro-benchmark. The full measurement trail lives in
`docs/loop-engineering/check-handoff-scaling.md`; this file records only the

- decision: fixed the `done`-axis cost with an early `exit` from the awk program the moment `## Active` closes, rather than any alternative (e.g. restructuring the extraction as a separate `sed`/state-machine pass, or pre-slicing the file with a range pattern before piping into awk).
  reason: the minimal, single-line change to the existing program (`in_active=0` → `exit`) preserves `NR` and the `!seen` single-section rule with no restructuring, and directly satisfies AC3's unconditional "done-axis after-arm 4x under twice after-arm 1x" requirement with the fewest new invariants to prove — the three invariants named in the spec's own Notes for engineer (NR unchanged, no-`## Active` file still reads to EOF, `!seen` still holds) all follow structurally from an `exit` placed exactly where the section-close branch already fired.
  grounding: bin/check-handoff.sh (current `active_block=` awk program, `in_active && /^## / { exit }`); .shell-team/specs/T-1070-check-handoff-scaling.md's Notes for engineer, first candidate-repair paragraph.
- decision: fixed the `active`-axis blank test by replacing `[[ -z "${content//[[:space:]]/}" ]]` with the anchored whole-string match `[[ "$content" =~ ^[[:space:]]*$ ]]`, rather than any other rewrite (e.g. a byte-length heuristic, a manual character-scan loop, or trimming via `${content## }`/`${content%% }`-style parameter expansion).
  reason: an isolated micro-benchmark showed the anchored match stays flat (0.000-0.004s) across a 32x length range in both `C` and UTF-8 locales, versus the original's super-linear blowup (32.372s at 10,802 chars under `C`), AND an eleven-case, two-locale equivalence check (including the locale-dependent U+3000/U+00A0 edge cases) showed the two forms agree on every tested input — the fix had to preserve the exact same locale-dependent blank/non-blank verdict, which AC4's two-locale differential input specifically exists to catch.
  grounding: docs/loop-engineering/check-handoff-scaling.md, `## Profile` section (the equivalence table and both micro-benchmark tables); bin/check-handoff.sh's blank-test comment.
