- decision: the `candidate-id-grammar` closed by `- selection-rule: candidate-id-grammar` is a fixed two-digit, zero-padded decimal ordinal (`candidate-01`, `candidate-02`, … up to `candidate-99`), rather than a letter-suffixed shape (`candidate-a`, `candidate-b`), a UUID-shaped id, or an unpadded ordinal (`candidate-1`, `candidate-2`, …).
  reason: **AC3** requires only that the fixed shape make byte-wise lexicographic order total over `candidate-id` strings — it does not fix the shape itself, so more than one compliant grammar was open. The zero-padded two-digit form was chosen because it is the smallest shape that already covers this repository's own recorded N (2 or 3, per the Input space) with headroom, avoids the specific defect an unpadded ordinal would introduce (`candidate-10` sorting lexicographically before `candidate-2`, breaking totality's usefulness the moment N reaches double digits even though total order technically still holds byte-wise), and mirrors this repository's own existing zero-padded rep/arm numbering conventions elsewhere in the corpus rather than inventing an unrelated one.
  grounding: `.shell-team/specs/T-1087-judge-briefing.md` **AC3**'s body ("The `candidate-id-grammar` line carries the literal `candidate-id` and fixes an id shape under which lexicographic order is **total**"); `docs/loop-engineering/tier2-judge-briefing.md`, the `- selection-rule: candidate-id-grammar` line.
- decision: the closed three-value ordinal scale anchoring `test-depth`, `scope-discipline` and `hygiene` uses the value names `full`, `partial`, `absent`, rather than numeric labels (`0`/`1`/`2`), letter grades, or a different three-word scale.
  reason: **AC2** requires one closed ordinal set with at least three identical values across the three criteria, but names no specific values — several compliant vocabularies were open. `full`/`partial`/`absent` was chosen because it maps directly onto each anchor's own binary-plus-partial structure (a named tree property is fully present, partially present, or absent) without borrowing vocabulary the contract already reserves elsewhere: `phase-multiplexing.md`'s own closed "Judge disposition words" are `pick`, `merge`, `none`, and reusing `none` as a per-criterion score value (a plausible alternative to `absent`) risked a reader misreading a per-criterion score as the disposition field itself.
  grounding: `docs/loop-engineering/phase-multiplexing.md`, the "Judge disposition words" line in `## Terms and closed vocabularies` (`pick`, `merge`, `none`) — the collision this decision avoids; `.shell-team/specs/T-1087-judge-briefing.md` **AC2**'s body ("holds at least three distinct values ... identical across all three criteria"); `docs/loop-engineering/tier2-judge-briefing.md`, the nine `- score-anchor:` lines.
- decision: the four `- candidate-rule-map:` lines assign `interface-not-changed` → `ac-pass-completeness`; `oracle-not-edited` and `paths-confined-to-manifest` → `scope-discipline`; `zero-dependency-bash` → `hygiene` — leaving no candidate rule mapped to `test-depth`.
  reason: **AC4**(i) requires each of the subject's four candidate-rule ids mapped onto some `judge-criterion` id, but does not fix which criterion each rule belongs to; more than one assignment was defensible (for example, `oracle-not-edited` could plausibly have been assigned to `hygiene` instead, as a "left something extraneous in the venue" framing). The assignment shipped ties each rule to the criterion whose own check would actually observe a violation of it: `interface-not-changed` maps to `ac-pass-completeness` because the oracle's own byte-exact enumerated-case comparisons are exactly what would catch a changed message, field order or exit code; `oracle-not-edited` and `paths-confined-to-manifest` both map to `scope-discipline` because both are, at root, about writing outside the manifest's declared path scope; `zero-dependency-bash` maps to `hygiene` because a foreign-interpreter dependency is not a byte the oracle's enumerated cases name, but is exactly the class of diff-cleanliness defect `hygiene` (rank 4) is defined to cover.
