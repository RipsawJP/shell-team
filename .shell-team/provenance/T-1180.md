- decision: In `bin/team-commit.sh` the base-dir test runs over every named path after the duplicate check and before `check_path` (so before any per-path state inspection and before `git add`), not inside `check_path` and not after it.
  reason: Putting it first makes the refusal class `local-mode` independent of whether the named file exists, is ignored or differs from HEAD, and a mixed request is refused as a whole with nothing staged; inside `check_path` an earlier per-path refusal of another path could pre-empt it and the result would depend on path order.
  grounding: `.shell-team/specs/T-1180-local-mode-declaration.md` D4 and AC4 (the mixed request `README .shell-team/todo.md`).

- decision: `bin/team-mode.sh` reads the key with `git config --local --get` and maps git's exit 1 to absent (`tracked`) and every other non-zero exit to its own exit 2 with nothing on stdout.
  reason: The alternative of an all-scopes read would let a global, `-c` or environment value select local mode for every clone; the alternative of treating any non-zero as absent would read a malformed repository file as `tracked`, which is the fail-open the spec forbids.
  grounding: `.shell-team/specs/T-1180-local-mode-declaration.md` D2 and AC1/AC7.

- decision: `bin/check-durability.sh` gets its notice and mode read as a block placed between argument validation and the `team-paths.sh` resolution, with the header gaining a paragraph and `print_help`'s range moved by the number of added header lines.
  reason: Reading before `team-paths.sh` means a local-mode run needs nothing else resolvable; keeping `--help` ending at the `--records` line preserves the adopter-readable help the spec requires, and a fixed range would otherwise have cut the new paragraph or reached the Exit paragraph.
  grounding: `.shell-team/specs/T-1180-local-mode-declaration.md` D3 and AC8.

- decision: The three scratch-copy fixtures of `tests/team-commit/run.sh` copy `team-mode.sh` from the directory of the script under test (`dirname "$SCRIPT"`), not from `$REPO_ROOT/bin`.
  reason: The suite lets `TEAM_COMMIT_SCRIPT` point at a different script, so the sibling has to come from the same place as the script, or the copy would mix two installs.
  grounding: `tests/team-commit/run.sh` header comment on `TEAM_COMMIT_SCRIPT`; `.shell-team/specs/T-1180-local-mode-declaration.md` D6.

- decision: Round-1 rework: `bin/team-mode.sh` captures git's output with a sentinel (`printf 'x%s' "$?"` appended inside the command substitution, so both the value's trailing line feeds and git's exit status survive) and compares against `local` plus exactly one line feed, git's own record terminator; `bin/check-durability.sh` and `bin/team-commit.sh` capture the resolver with `&& printf x` and match `tracked`/`local` plus one line feed plus the sentinel.
  reason: A plain `$(...)` strips every trailing line feed, so a stored `"local\n"` (printed as `local`, line feed, terminator) compared equal to `local` and selected the fail-open mode; the alternative of `git config -z` plus stripping one NUL was not chosen because the sentinel form needs no change in how git is called and keeps the exit-status mapping of D2 unchanged. One terminator is removed by comparing against `local$nl` rather than by stripping, so a value with a line feed anywhere is `tracked`.
  grounding: `.shell-team/specs/T-1180-local-mode-declaration.md` D2 ("exact byte string `local` (no case folding, no trimming)") and D3 (output other than exactly `tracked` or `local` is structural); `.shell-team/reviews/T-1180.md` Major and first Minor.

- decision: `tests/team-mode/run.sh` compares captured stdout with `cmp` against an expected file for every resolver and skipped-line case, and adds stored-value cases for a quoted `local` followed by one and by two line feeds, an embedded line feed and a leading line feed, plus resolver stubs printing the word and two line feeds for both consumers; the frozen AC1 variant list is not changed.
  reason: The line-feed values are not covered by AC1's frozen list, and the operator ruled the rework needs no re-freeze, so the suite that AC10 runs carries them.
  grounding: `.shell-team/reviews/T-1180.md` third Minor; the board entry's operator-gate line for T-1180.
