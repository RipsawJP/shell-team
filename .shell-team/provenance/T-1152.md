- decision: The shipped `codex exec` blocks become single bare commands — `--json -o "<RAW_OUT>"` with no `< /dev/null`, no `> "<RAW_JSONL>" 2>&1` and no `"$(cat …)"` argument — because Claude Code 2.1.278 and later exempt a Bash command from the sandbox only when every part of it matches `sandbox.excludedCommands`.
  reason: Measured on Claude Code 2.1.281 with codex-cli 0.156.1 (2026-09-24), each Bash tool call one probe: the bare form `codex exec --sandbox read-only --cd <repo> --json -o <out> "<prompt>"` exited 0, Codex ran its own command and wrote `-o`; the shipped form with a trailing redirection exited 1 with `Reconnecting… (workspace routing discovery failed)` twelve times and `turn.failed`, no `-o` written, no `sandbox_apply` string (the tool was never reached); the `"$(cat <file>)"` argument form failed identically; a literal prompt naming the briefing file's absolute path and a backslash-newline-continued quoted prompt both ran normally. On 2.1.278 the same shipped form degraded silently (exit 0, `-o` = `Unable to determine.`, `sandbox_apply` in the stream) — the shape recorded in issue #586.
  grounding: .shell-team/specs/T-1152-codex-sandbox-hotfix.md — `## Problem` and `## Assumptions` (probe table A, B, (a)–(d)); the official Claude Code CHANGELOG entries for 2.1.277 ("every part must now match"), 2.1.278, 2.1.280 and 2.1.281.

- decision: `bin/codex-capture.sh --publish` gains `--thread-id <id>` and imports Codex's own persisted rollout file as the `.jsonl` raw, instead of dropping the JSONL raw or capturing the stream by redirection.
  reason: Codex persists every thread's full event record itself at `${CODEX_HOME:-$HOME/.codex}/sessions/<YYYY>/<MM>/<DD>/rollout-<timestamp>-<thread_id>.jsonl`, and the thread id is the first `--json` stdout event, `{"type":"thread.started","thread_id":"<uuid>"}`. Three rollouts were read line by line: a successful run has one `event_msg`/`item_completed` line per executed command with `"item":{"type":"CommandExecution",…,"exit_code":N}` and ends with an `event_msg` `task_complete` line carrying a string `last_agent_message` and no `error` key; the sandboxed failed run has zero `CommandExecution` lines and a `task_complete` line with `"last_agent_message":null` and `"error":{"message":"workspace routing discovery failed",…}`. The format is measured at codex-cli 0.156.1 only: `codex migrate-rollouts` calls these files legacy, so the import fails closed with a diagnostic naming the searched directory and thread id.
  grounding: .shell-team/specs/T-1152-codex-sandbox-hotfix.md — `## Goal`, AC4–AC8 and `## Assumptions`; .shell-team/interventions/T-1152.md — the two `assumption-contradicted` entries.

- decision: The publish gate refuses (exit 3, "review did not run") when no `CommandExecution` line has `"exit_code":0`, or when the last `task_complete` line has a null `last_agent_message` or a non-null `error`; `failure_markers` is reported but never gates.
  reason: A sandboxed run on 2.1.278 can record its failed tool calls as `CommandExecution` items that exit non-zero and still end with a string final message, so counting executed commands alone would pass it; a review with no succeeding command has read nothing. Gating on the marker strings would refuse legitimate reviews of this plugin, whose own diffs contain those literals in prose.
  grounding: .shell-team/specs/T-1152-codex-sandbox-hotfix.md — AC5, AC6 and `## Notes for engineer`; the orchestrator's rulings v2 §5 (R3'), summarized in `## Summarized sources`.

- decision: The alternate-executor recipe line drops `--ephemeral` and keeps `--ignore-user-config --ignore-rules`.
  reason: `codex exec --ephemeral` runs "without persisting session files to disk" (its own `--help`); a bare recipe-shaped probe with `--ephemeral` completed (exit 0, `-o` written, one command executed) and zero session files match its thread id, so a `--publish --thread-id` for that run can never find its source and the recipe's read-scope audit has no record. The two remaining flags carry the part of the recipe's isolation that governs what Codex reads.
  grounding: .shell-team/specs/T-1152-codex-sandbox-hotfix.md — AC3, `## Blast radius` (merged T-1118 AC3 and T-1119 AC1 predicted red) and `## Assumptions`; .shell-team/interventions/T-1152.md — the second `assumption-contradicted` entry.
