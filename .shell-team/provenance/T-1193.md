- decision: The unterminated-string verdict is decided in the tokenizer by whether the closing quote was found (a `closed` flag), and a line with such a string is counted malformed and skipped before any type filtering.
  reason: A last-byte test on the token accepts a string ending in an escaped quote and rejects a well-formed one ending in an escaped backslash; an unterminated string can also swallow the type key, so a verdict limited to lines whose type was read would miss the dangerous case.
  grounding: `.shell-team/specs/T-1193-capture-extraction-fail-closed.md` D1 and AC1 (the u7, u8 and u9 fixtures) and `## Notes for engineer` (Extraction).

- decision: Depth-1 `type` keys are counted at key time (the string followed by a colon at depth 1), not from their values, and a count above one is malformed on any line the extraction reads.
  reason: Counting string values would miss a non-string value beside a string one, and counting at any depth would flag every real record, whose payload carries nested `type` keys.
  grounding: `.shell-team/specs/T-1193-capture-extraction-fail-closed.md` D2 and AC2 (the d5 and d6 fixtures).

- decision: The T-1193 fixture block carries its own mutation probes and sits before the T-1192 mutation self-check; its probes assert the mutant no longer refuses as `cause=malformed` instead of asserting exit 0.
  reason: With the unterminated verdict dropped, the swallowed line leaves no model and the rollout is still refused, as `cause=absent`, so an exit-0 assertion would fail the probe for the wrong reason.
  grounding: `.shell-team/specs/T-1193-capture-extraction-fail-closed.md` `## Notes for engineer` (Where to place the T-1193 block, Mutation probes).
