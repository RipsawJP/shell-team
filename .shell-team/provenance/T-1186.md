- decision: The CR byte is detected with `grep -q` against a CR value built by `printf '\r'` and the status taken explicitly (0 note, 1 none, other is exit 2), after a separate `-f`/`-r` check, instead of a `tr`/`od` pipeline or a here-string.
  reason: `grep -q` distinguishes no-match (1) from error (2) in one call, writes nothing and needs no here-string; the separate readable test makes a missing file fail closed rather than read as "no CRLF".
  grounding: `.shell-team/specs/T-1186-crlf-line-endings.md` `## Notes for engineer` (`Detection`) and D2 (`Fail closed`).

- decision: The new suite cases build their own plugin copy and a dedicated fixture repository and read through a local `ckp` helper that mirrors `ck` (TMPDIR pointed at `$T/tmpd`), rather than calling `ck` with a different checker path.
  reason: `ck` is bound to `$C`, the real script; the CRLF cases must run the copy's checker so its plugin root is the converted copy, and keeping `TMPDIR="$T/tmpd"` preserves the suite's empty-scratch assertion.
  grounding: `.shell-team/specs/T-1186-crlf-line-endings.md` AC3 (`Setup`, `Nothing written`) and D3.
