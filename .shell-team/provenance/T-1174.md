- decision: The settings reader is a strict JSON recogniser written in awk (valid document, exactly one `sandbox` key at the top level, exactly one `excludedCommands` key as its direct member, an array holding the exact string element), counting those keys over the whole document rather than only at the expected nesting level.
  reason: A hand-rolled regex cannot track quote and nesting state, and counting every occurrence makes a nested look-alike or a duplicate key fail closed to "could not determine" instead of being read as the entry.
  grounding: `.shell-team/specs/T-1174-setup-report-handoff.md` decision 4 and AC8.

- decision: When more than one of the three settings files holds the entry, the report names only the first in the order user, project, local, as one line.
  reason: The criteria require exactly one `- sandbox: ` line under `Already in place:`, and the entry's effect on the session is stated as not determined whichever file is named.
  grounding: `.shell-team/specs/T-1174-setup-report-handoff.md` decision 4 and AC7.

- decision: The git ignore report is read by rewriting the NUL-terminated stream to newline-separated fields (NUL to newline, newline to a control byte) inside a command substitution, with a line-count integrity check, instead of writing a temporary file.
  reason: A temporary file would add a write outside the documented write set and a cleanup path, and the rewrite keeps every field boundary unambiguous even when an untrusted pattern or a source path carries odd bytes.
  grounding: `.shell-team/specs/T-1174-setup-report-handoff.md` decision 3 (the `-z --stdin` field reading) and decision 7.

- decision: A re-include line is printed for a directory only when every ignored probe under it is reported from the global excludes file or info/exclude with a closed-set pattern and no ancestor directory is itself reported ignored; the printed command names a directory only when its anchor is not in HEAD, plus the root .gitignore when a re-include line is printed, and is omitted when that list is empty.
  reason: The ratified option A forbids rule-interaction derivation, and a command with no path would not be a valid git add.
  grounding: `.shell-team/specs/T-1174-setup-report-handoff.md` `## Planning decision (operator-ratified, option A, 2026-10-05)` and AC4 to AC6.

- decision: A required directory whose resolved path has a character outside `[A-Za-z0-9._/-]` gets neither a re-include line nor a printed command, and the line says the path cannot be quoted safely.
  reason: The loop's commit script refuses such a path, and printing a command that names it could break its own quoting.
  grounding: `.shell-team/specs/T-1174-setup-report-handoff.md` Input space, out-of-scope extreme 7.
