- decision: Each of the eight bin tools empties its own mktemp directory with one non-recursive glob (`rm -f "$DIR"/*`) and then `rmdir`, instead of removing a hand-maintained list of file names.
  reason: Four tools create indexed names (`part.$i.raw`, `claims.$i`), and `check-board-headings.sh` creates files inside command-substitution subshells whose names the parent never learns, so a name list would drift or be impossible; the glob skips dotfiles, so an unknown dotfile makes `rmdir` refuse and the directory is left in place, which the spec accepts.
  grounding: `.shell-team/specs/T-1165-no-recursive-delete.md` `## Notes for engineer` (Tool cleanup shape) and **AC4**/**AC5**.

- decision: Every cleanup is wrapped in `if [ -n "${DIR:-}" ] && [ -d "$DIR" ]` and ends each command with `|| true`.
  reason: An empty or unset variable would turn `"$DIR"/*` into `/*`; the guard removes that failure mode, and the `|| true` keeps the original exit status when a removal or `rmdir` fails (N3), including under `set -e` in an EXIT trap.
  grounding: `.shell-team/specs/T-1165-no-recursive-delete.md` pre-commitment N3 and **AC4**.

  reason: Every tool's scratch layout is a flat directory (two levels for `check-codex-agents.sh`) that a non-recursive glob plus `rmdir` empties; the shim case measures one leftover on a failed `rmdir` and none on a normal run in all eight suites.
  grounding: `.shell-team/specs/T-1165-no-recursive-delete.md` **AC5** (D1 clause).
