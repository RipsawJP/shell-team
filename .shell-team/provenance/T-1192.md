- decision: The observed model is read by a dedicated awk pass (`extract_model` in `bin/codex-capture.sh`) that runs after the completed-run gate, instead of adding model fields to the gate's own awk program.
  reason: Two readers could have carried it. A separate pass leaves the gate program and every base refusal message byte-for-byte as they were, so the base-identity pairs of AC2 hold by construction, and it lets `--observe` reuse the extraction without the gate.
  grounding: `.shell-team/specs/T-1192-codex-review-model-pin.md` D3 (the Extraction bullet) and AC2.

- decision: `--observe` does not apply the completed-run gate, and refuses `--stem`, `--reviews-dir`, `--publish-out` and `--publish-jsonl` with exit 2.
  reason: The spec fixes `--observe` as a read-only mode that resolves no reviews dir and writes nothing, so a gate that exists to protect a publish has no place in it, and an accepted-but-ignored publish argument would let a caller believe a capture was made.
  grounding: `.shell-team/specs/T-1192-codex-review-model-pin.md` D3 (the read-only `--observe` bullet) and AC9.

- decision: A backslash-u escape inside any KEY string of a `session_meta` or `turn_context` record counts as `malformed` in the extraction, in addition to the spec's value-side rule.
  reason: `--observe` runs no gate, and a key spelled through an escape could hide a `model` key from a reader that compares key text byte-wise; failing closed is cheaper than reasoning about which side decodes it. Under `--publish` the completed-run gate already refuses such a rollout first, so no publish outcome changes.
  grounding: `.shell-team/specs/T-1192-codex-review-model-pin.md` D3 (the `cause=malformed` bullet) and `bin/codex-capture.sh`'s own header on the gate's `\u` rule (T-1152 round 2).

- decision: The refusal line names the cause but never echoes the observed value, a mismatch included.
  reason: The observed value is repository-external text read from a rollout; the closed cause set carries what a reader acts on, and the same no-echo rule then holds for every cause without a per-cause exception.
  grounding: `.shell-team/specs/T-1192-codex-review-model-pin.md` D3 (the Comparison bullet) and `## Notes for engineer` (No echo).
