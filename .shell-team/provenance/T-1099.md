- decision: heading-occurrence log lines are tagged `ACTIVE` / `DONE` / `OTHER<TAB><identity>`, and the "other" bucket's duplicate check is implemented with `awk -F'\t' '$1 == "OTHER" { print $2 }'` rather than `grep` on a literal embedded tab byte.
  reason: a literal tab character embedded in a shell pattern string (for `grep -F`/`grep`) is fragile to transcribe and re-quote correctly across GNU and BSD grep, and an initial attempt using `grep -P` for a `\t` escape is not portable (BSD/macOS grep has no `-P`). `awk -F'\t'` reads the tab as a field separator natively in both awk implementations this repo already relies on (the file's own header states awk is the shared parsing tool), with no quoting hazard.
  grounding: measured directly in this session — a first draft using `grep -P '^OTHER\t'` was rejected before being tested (macOS ships BSD grep without `-P`); the final `awk -F'\t' '$1 == "OTHER" { print $2 }'` form was run against all 15 new fixtures and produced the expected identities in every case (verified via manual invocation, recorded in the hand-off).
