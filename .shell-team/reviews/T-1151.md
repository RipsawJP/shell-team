The adversarial pass, briefed with this exact reproduction, independently confirmed the trace and additionally confirmed (own read of `bin/check-adopter-docs.sh:559-611`) that no other mechanism in the file closes this gap — declaration-duplicate suppression does not help (every `R`-recorded declaration is still counted, so a legitimate declaration plus a sneaky second one anywhere in `R`'s open window trips `declaration-duplicate` rather than hiding the sneaky one), `marker-conflict` only fires for a `shipped-docs:` beside a `no`, and `S` (AC scope) is unrelated to this family's positional check.
