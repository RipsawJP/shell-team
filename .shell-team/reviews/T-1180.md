#### Major
- major — `bin/team-mode.sh:71` and `bin/team-mode.sh:81` — `val="$(git config --local --get shell-team.mode)"` strips every trailing line feed, so a stored quoted value `"local\n"` (git emits `local`, line feed, then its own record terminator) compares equal to `local` and the resolver prints `local`. Reproduced in a scratch repository under `$TMPDIR`: the config holds `mode = "local\n"`, `git config --local --get` prints `local` plus two line feeds, and `bash bin/team-mode.sh` printed `local`. D2 freezes "the exact byte string `local` (no case folding, no trimming)"; this is a non-exact value read as the fail-open mode (`check-durability.sh` then skips every observation). It is a narrow input (an operator must type an escape sequence), but the direction is the unsafe one and the fix is two lines. Suggested fix: capture with a sentinel, `val="$(git config --local --get shell-team.mode; printf x)"`, then `val="${val%x}"` and remove exactly one trailing line feed (git's terminator) before the comparison, or read with `-z`. Add a `local\n` value case to `tests/team-mode/run.sh` and to AC1's list on the next freeze.

#### Minor / nits
- minor — `bin/check-durability.sh:200` and `bin/team-commit.sh:257` — the same `$(...)` capture of the resolver output strips extra trailing line feeds, so an out-of-set output such as `local` followed by blank lines is accepted as `local` or `tracked`. D3 says an output other than exactly `tracked` or `local` is `structural`. Only a replaced or modified resolver can produce it; the shipped resolver prints exactly one line once finding 1 is fixed. Suggested fix: the same sentinel capture and an exact comparison against `tracked\n` / `local\n`.
- minor — `tests/team-mode/run.sh:47` — `OUT="$(cat "$T/out")"` also strips trailing line feeds, so the suite cannot detect extra bytes after the line; compare the captured file against an expected file byte for byte.
- nit (QA risk notes, read and settled) — a grammar-invalid path under the base dir is refused as `local-mode` rather than `path` (`bin/team-commit.sh:380-392` runs before `check_path`); still exit 2 and before any write.
