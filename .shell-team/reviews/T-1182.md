#### Minor / nits
- minor (finding 1) — `bin/check-pii-shapes.sh:871` — a named path on the closed known-shape fixture list is skipped without a notice; `--paths <known-shape file> clean.txt` exits 0 with the clean line because the clean file satisfies the read counter. Default and `--all` skip the same list identically. Suggested fix: print a `skip:` notice for a named known-shape path, or count it as unread.
- minor (finding 2) — `bin/check-pii-shapes.sh:881` — the symlink, type and readability tests and the later `cp` address the file by pathname at separate times, so a concurrent replacement could redirect the read. Suggested fix: narrow the docs' claim or read through one descriptor.
- minor (finding 3) — `bin/check-pii-shapes.sh:837` — trailing slashes are stripped before resolving, so `--paths file.txt/` scans the regular file and reports clean instead of refusing a path that names a directory. QA noted the same lenient behaviour. Suggested fix: keep the slash and exit 2 when the entry is not a directory.
- minor (finding 4) — `bin/check-pii-shapes.sh:831` — the path-list append and the symlink-target write rely on `set -e`; a failed write exits 1 with no `FINDING` line instead of the documented 2. The existing `--all` list write has the same shape. Suggested fix: guard those writes and route them through the structural-error exit.
- nit (finding 5) — `bin/check-pii-shapes.sh:844` — `cd "$parent" && pwd -P` follows a symlinked parent component, so `linkdir/f` scans the physical target and reports its physical path; an in-repo link can reach `.git` contents. Suggested fix: document it as the intended physical resolution.
- nit (finding 6) — `docs/pii-controls.md:142`, `docs/pii-controls.ja.md:133` — the loop sections say a no-record round reports a zero count but omit the `rc=n/a` the prompt block states. Suggested fix: add the three characters in both languages.
- No finding on the block line or its four mirrors, the default, `--base` and `--all` paths, the usage text, the fail-closed exits, the `.git` pruning, or the suite and docs structure.
