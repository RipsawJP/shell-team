"checkout is clean" assertion, so K1 classifies it **non-conforming**,

<base>...HEAD` or the ancestor-equivalent two-endpoint form, plus the
`ls-files --others` union if it's genuinely a scope lock).

```

```
This is the unscoped recursive-grep absence assertion K2's own text names
verbatim as the failure shape: "An unscoped `grep -rn <identifier> .` reads
whatever happens to be on disk: one gitignored build artifact or compiled
cache older than the base ref... is enough to fail a criterion whose source
tree is clean." K2 classifies this **non-conforming**, determinately, with
the repair named in the same bullet (name the files outright, or restrict
with `--include=<glob>`/`--exclude-dir=<dir>`).

Both bullets let a reader reach a determinate verdict without ambiguity for
the constructed non-conforming case. One boundary note for the record rather
