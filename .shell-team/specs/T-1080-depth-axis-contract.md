### Verdict scope and per-artifact review depth (freeze-time pricing)

Stated here so a review briefing inherits it rather than re-deriving it, and so the two halves of this deliverable are not priced alike. **`agents/codex-reviewer.md`, `agents/qa-verifier.md`, `skills/run/SKILL.md` and `bin/loop-guard.sh` are shipped surfaces an adopter loads and executes — adversarial depth, no carve-out.** A finding that an amendment silently changes today's serial behavior while declaring itself conditional, that the two agent files' halves of one norm disagree, or that an amendment is descriptive where it needed to be prescriptive, is verdict-gating at full severity. **`docs/loop-engineering/agent-concurrency.md` is an internal research note — note depth.** For the note half only, and only for it, a finding about connective prose (a summarising sentence, a label mismatch, a stale narrative aside) that leaves every corrected value correct and every conclusion's direction intact is recorded as a note rather than as a verdict-gating Blocker or Major. No escalation ratchet is created over any prose class on either half.

**D1 — the framing is conditional, and the condition is a window this loop cannot enter.** Every amendment below is written as "in serial operation — the shipped default and the only mode today — X is unchanged; inside a declared `concurrent-review-window`, Y." The alternative was considered and rejected: making any rule unconditional (forbidding QA's test-only edits outright, pinning the reviewer's read to a SHA always) would change today's behavior, would flip the `- user-visible:` declaration to `yes`, and would ship a cost on every serial run to buy safety for a mode nobody can run. The window is **declared by the coordinating session in a role's launch brief** and by nothing else: no script sets it, no board flag carries it, no default enters it. That is what makes the whole set inert today and is exactly why the criteria below can only verify text — a point **D8** prices rather than hides.

**D2 — one window token and five record tokens, not seven paragraphs of prose.** A role cannot act on a condition it cannot name, and two roles cannot agree about a condition each names differently.
