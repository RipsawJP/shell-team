## Problem

`bin/resolve-executor.sh` decides, fail-closed, which executor each of the six bound roles may be invoked through — and the two standalone review commands never call it. `skills/review/SKILL.md` invokes `codex-reviewer` directly at its one invocation sentence; `skills/review-response/SKILL.md` hands findings to `codex-reviewer` at its Step 2 Agent-tool call without resolving anything first. `templates/prompt-blocks/registry.txt` machine-proves the boundary: the `contain executor-resolution.md` row names `skills/run/SKILL.md` and `skills/goal/SKILL.md` and nothing else. The consequence is that a host-authored `<base>/binding.conf` — including a malformed one the resolver would refuse fail-closed — gates **nothing** whenever a review is invoked outside the run/goal loop. T-1060 resolved the documentation side by scoping the claim down to today's truth and citing issue **#245**; the mechanism side is this task, and the same sentence T-1060 wrote to be re-widened is re-widened here.

## Input space

**Reachable input classes** — what this task's deliverables really face:

- **`bin/check-prompt-sync.sh` faces the registry rows and consumer files as committed.** The classes that matter: a `contain` row with two, three or four consumers; a consumer carrying the canonical core plus a tail on one physical line; a consumer with CRLF line endings (normalized by the checker's own `${line%$'\r'}` strip); and a registered consumer file that is missing (exit 1) or a registry that is missing or holds an unknown mode (exit 2). - **`bin/resolve-executor.sh` faces the `<base>/binding.conf` shapes an ordinary adopter edit produces**, which are the shapes the two review commands' new gate will actually meet: **absent** (the plugin default is the effective binding), **well-formed**, **grammar-refused** (a wrong field count, an unrecognized provider/adapter/role token, a partial file missing rows), a **non-regular-file occupant** (a directory, a FIFO, a dangling symlink), and an **effort value the bound adapter does not declare**.
