**Status**: READY_FOR_ARCH

## Problem

A machine-local session path — a temp root, a home-directory segment whose slashes had been replaced by hyphens, and a session UUID — reached a frozen spec's `## Summarized sources` citation in the trust-gates cycle and was caught only by the cross-provider review's round-1 Major. `bin/check-pii-shapes.sh` was running on that very pull request and reported clean, because both of its home-path rules require a literal `/Users/` or `/home/` that a hyphen-encoded segment never contains, and no shipped rule looks for a UUID-bearing temp segment at all. The class is mechanically detectable and has no legitimate place in tracked prose in a public repository, so the gate — not authoring discipline — is where it belongs. Two tracked files carry the shape today, so the extension reds this repository's own required CI check until the same commit repairs them.
