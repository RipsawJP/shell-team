# Setup's report hands off: the review transfer is a notice, settled host conditions are already in place, the base directory is a required action

**Status**: READY_FOR_ARCH
**Owner**: pm-spec
**Task ID**: T-1174

## Problem

On a Claude Code host, `bin/team-setup.sh` ends every run with four host-side lines under `Remains the operator's decision:` — the sandbox, commits, whether to track the base directory in git, and the review transfer (`bin/team-setup.sh:491-496`). In the adopter run reported in issue #689, three of those four were answerable from state setup can read: the operator's user-level settings already excluded `codex *` from the sandbox, the global excludes file hid `.shell-team/` with no repo-level re-include, and the review transfer is a fact about the review pass rather than a choice setup can act on. The operator's own words: setup left four decisions and nowhere to record them, and the Codex/OpenAI transfer should only be shown as a notice. A base directory that git ignores is not a choice at all: the loop does not support never-committed operating files (`docs/adopting.md:942`) and `bin/team-commit.sh` refuses ignored paths (`bin/team-commit.sh:295-301`), so it has one correct answer and setup should state it.

**Decisions frozen here** (each is promoted to a criterion):

1. **Report shape.** Stdout is one header line, then five headings, each exactly once and in this order: `Done:`, `Already in place:`, `Remains the operator's decision:`, `Required:`, `Notice:`. 3. **Required: the base directory.** The *required directories* are the base directory (`team-paths.sh --get base`) and, when `team-paths.sh --get specs` resolves outside it, the specs directory. Each has an *anchor*: the board for the base directory, and `<specs>/.gitkeep` (written by `team-init.sh`) for an outside specs directory. Setup asks git whether the board, the loop contract (`team-paths.sh --get loops`/`shell-team.contract.yaml`, a deeper scaffold path), each anchor and a not-yet-existing `.md` path directly inside each required directory are ignored, and whether each anchor is in `HEAD`'s tree; an unborn `HEAD`, or an anchor that is only staged, counts as not committed.
