## Input space

**Reachable input classes** — what this task's criteria really read and must handle correctly:

- **This repository's own tracked markdown, at `a804703` and at `HEAD`**: two agent prompt files (UTF-8, LF, hand-written prose bullets interleaved with `<!-- BEGIN/END prompt-block: … -->` marker regions), four spec files (frozen-block HTML comments, `- [ ] **ACn**` criterion bullets, `- check:` sub-bullets carrying both quote kinds, `$( )`, em-dashes, asterisks and backticks mid-line), and the board (top-level `- [` entry lines with two-space-indented sub-bullets, several thousand lines, entries whose sub-bullet labels collide across entries).
- **`git`'s own output for a named ref**: `git show a804703:<path>` blobs, `git diff --numstat` rows (two integers and a path, or nothing at all when a file is unchanged), `git ls-tree -r --name-only`, and `git ls-files --others --exclude-standard`. An unresolvable ref, an empty blob, and an empty diff are each reachable and each must fail closed rather than read as a clean result.
- **Frozen-block content carrying characters that are regex-significant**: em-dash (U+2014), backticks, `$`, `*`, `[`, `(`, `\`. Every criterion consumes these as fixed strings fed from a file (`grep -F -f`, `cmp`) and never interpolates them into a pattern.
- **A frozen block whose extraction yields zero lines or more than one** — reachable from a mistyped marker name or a hand edit — and asserted as a failure by every criterion that extracts one.
- **A spec corpus that grows between authoring and check time**: AC11 re-derives its population live, so a spec added or removed under `.shell-team/specs/` is a reachable input that reddens the criterion rather than silently narrowing it.
- **A leading-space-indented board sub-bullet whose text repeats verbatim in another entry** (`- freeze-attestation (`, `- intent-hash (`): AC6 extracts per entry rather than grepping board-wide precisely because this class is real.

**Out-of-scope synthetic extremes** — inputs this spec explicitly declines to protect against:

- **A tracked filename containing a newline, tab, or a byte `core.quotePath` would C-style-quote.** This corpus is hand-curated and commits none; the line-oriented reads of `git ls-files` and `git ls-tree` here are accepted as sufficient, exactly as `.shell-team/specs/T-1044-test-infra-bundle.md`'s own Input space accepted them.
- **A NUL byte or invalid UTF-8 inside a tracked markdown file.** Committing one independently breaks that file as the markdown every existing gate already parses; it is a design decision needing a spec, not an input class to accommodate.
- **An adversarially planted marker** — a nested, duplicated or forged `<!-- frozen-begin: … -->` pair, or a `<!-- BEGIN intent-block: … -->` marker inside a fenced block — designed to defeat the `awk` extraction. Every extraction asserts an exact line count, which fails closed on it; no criterion is widened to detect a deliberate forgery.
- **A hostile `$TMPDIR`**: an attacker-controlled temp directory, a symlink race against `mktemp -d`, or a permission flip between creation and first write. Same class T-1044's Input space declined, and declined here for the same reason.
- **A concurrent writer mutating the working tree during a criterion run** (the writer-collision class recorded in `.shell-team/interventions/T-1051.md`). That is a run-discipline matter for the executing side, not an input class these criteria accommodate.
- **Ever-larger synthetic agent prompts or spec files** — a `## Rules` region with hundreds of bullets, a spec with hundreds of criteria, a board with tens of thousands of lines. Real data in this repository produces none of these, and a finding whose only trigger is one of them is `out-of-input-space`.
- **An agent prompt written in a language other than English**, or one whose `## Rules` heading is spelled differently. `CLAUDE.md`'s Language section fixes agent-facing files to English with no translated counterpart; a criterion is not widened to survive a hypothetical translation.
