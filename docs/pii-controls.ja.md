# PII 対策

[![English](https://img.shields.io/badge/lang-English-lightgrey?style=flat-square)](pii-controls.md)
[![日本語](https://img.shields.io/badge/lang-日本語-1f6feb?style=flat-square)](pii-controls.ja.md)

shell-team は公開の場で開発しているため、PII の混入は一度きりの移行リスクでは
なく、コミットのたびに発生し得るリスクになる。`bin/check-pii-shapes.sh` は
このリスクに対する機械的なゲートである。既定では変更が**追加した**内容だけを
見る（ベース参照に対する diff-scoped であり、ツリー全体は見ない）。fail-closed
であり、入力を評価できなかった実行が clean と報告することは無い。

## 何を検出するか

汎用で公開可能な 5 つの形状を、それぞれ安定したパターン id で識別する:

- `home-path` — 実在の名前セグメントを持つ POSIX のホームディレクトリ絶対パス
  （プレースホルダ形式 `/Users/<name>/` は意図的に非一致。後述）。
- `home-path-win` — Windows の `C:` ユーザーディレクトリ形式
  （`C:\Users\<name>\`、同じプレースホルダの慣習）。
- `email-nonnoreply` — 実在ドメインのメールボックス形状の文字列。GitHub の
  noreply 識別子の 2 形状（`<id>+<login>@users.noreply.github.com` と、素の
  web-flow 形式 `noreply@github.com`）は意図的に検出対象外である。これらは
  GitHub 自身の設計による公開識別子であり、PII ではない。
- `private-key` — PEM 形式の秘密鍵ヘッダー行。
- `token` — 実際の鍵本体と言えるだけの長さを持つ資格情報トークンのプレフィックス
  （GitHub の `gh[oprs]_`、AWS のアクセスキー ID、OpenAI 形式の `sk-` キー）。
  このプロジェクト自身の `task-0NN` ラベル慣習のような短い見た目だけの一致は
  対象外である。

## 実行方法

```bash
bin/check-pii-shapes.sh                 # 既定のベースに対する diff-scoped
bin/check-pii-shapes.sh --base develop  # 明示した参照に対する diff-scoped
bin/check-pii-shapes.sh --all           # フルツリー監査（後述）
```

終了コード: `0` clean、`1` 1 件以上の検出、`2` 使用法/構造エラー（解決不能な
ベース参照、読み取り不能な入力、未知のフラグ、`--all` と `--base` の併用）。
検出結果は一致したテキストそのものを出力しない — パターン id・パス・（可能な
場合の）行番号だけを報告する。これにより公開 CI ログにゲートを発火させた
バイト列が載ることはない。

`--all` はフルツリーの監査モードであり、必須の CI チェックではない。`tests/`
配下に既に存在する意図的な PII 形状の敵対的フィクスチャ（このプロジェクト自身の
ガードが実際に発火することを証明するためのもの）を必ず報告するため、この
リポジトリで実行すれば常に何かを検出する。現在の diff より広く掃きたい時に
ローカルで使う。

## このゲートが扱わないもの
- 固有名詞（顧客名・内部ホスト名・プロジェクトコード）は形状では一致させられないため、このゲートの対象外である。
- 固有名詞に一致させるためのパターン自体が機密であるため、この公開リポジトリには置けない。リポジトリ外のオペレータ手元のチェックに置く。
- 意味的な機微さ（設計判断や文脈から読み手が業務上の関係を推測できてしまう類）は PII の形状ではなく、対象外である。
- 画像の内容は検査しない。検査するとしてもメタデータのみである。

このゲートは形状だけを見る。PII 対策として完全ではなく、通過したことは変更に PII が含まれないことの証拠にはならない。

## 既知の制約

追跡されていないファイルは diff を持たないため、既定の diff-scoped モードでは
検査されない — それらを見るのは `--all` モードである。
