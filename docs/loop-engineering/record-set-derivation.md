# `bin/derive-populations.sh` — this task's own dogfooded derivations

T-1071 (`.shell-team/specs/T-1071-record-set-derivation.md`) ships a helper
whose whole point is that a record embeds a tool's output rather than a
hand-derived number. This note is that task's own record, held to the same
standard: every derivation block below is regenerated by re-running its own
`- reproduce:` line, never hand-edited after the fact — that is exactly what
**AC8** checks (byte-for-byte, against the command's live output), and it is
what a reviewer or a future rework should do too, rather than trusting the
prose around each block.

Both derivations below use the pinned collation (`LC_ALL=C`, recorded on
each block's own `- locale:` line) and read either a file this task has
finished editing (the registry row, stable from this point on) or a ref that
cannot move (the branch point's committed tree) — per the guidance in the
spec's Notes for engineer, so neither block drifts between this task's own
run and a later re-run.
